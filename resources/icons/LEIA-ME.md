# Ícones

Ícones **Material Symbols** (estilo *Outlined*, peso 400) da Google — <https://fonts.google.com/icons>.

Copiados do pacote npm `@material-symbols/svg-400@0.48.2`, licença Apache 2.0.
Só estão aqui os ícones usados na plataforma; usam-se com `<x-icone nome="..." />`.

Para acrescentar um ícone, procure o nome em fonts.google.com/icons e copie o
ficheiro `outlined/<nome>.svg` do mesmo pacote para esta pasta (sem `width`/`height`).
